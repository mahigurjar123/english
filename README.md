# सीखो — English Seekho, Hindi Mein

Ek interactive, single-page website jo Hindi-speaking beginners ko zero se English seekhne mein madad karti hai — pronunciation, grammar, 12 tenses, roz-marra ki conversation, aur 30-din ka vocabulary plan, sab kuch Hindi mein samjhaya gaya.

## Kaise dekhein

Bas `index.html` ko kisi bhi browser mein khol lijiye — koi installation ya server ki zaroorat nahi hai.

GitHub Pages ke through live dekhne ke liye: repo settings mein Pages enable karke `main` branch se serve karein.

## Sections

- **Foundations** — Alphabet, pronunciation, tricky sounds (TH, silent letters, V/W)
- **Parts of Speech** — Noun, Pronoun, Verb, Adjective, Adverb, Preposition, Conjunction (40-54 examples each)
- **12 Tenses** — Har tense ke 50+ example sentences, Hindi grammar rules ke saath
- **Modals, Active-Passive Voice, Narration** — Can/Could/Should/Must, passive conversion, direct-indirect speech
- **Daily Conversation** — Greetings, Restaurant, Interview, Shopping, Phone
- **Common Mistakes** — Galat vs Sahi comparisons
- **Word Power** — Advanced vocabulary, phrasal verbs, idioms
- **30-Day Plan** — Har din 20 words + 20 sentences
- **Practice Quiz** — Instant feedback ke saath

Har English word/sentence teen format mein diya gaya hai: English → Hindi Pronunciation → Hindi Meaning.
